# Security Policy

Report suspected vulnerabilities through [GitHub private vulnerability reporting](https://github.com/archledger/intel-npu-stack/security/advisories/new).

Do not open a public issue containing exploit details, credentials, tokens, recovery material, host identifiers, hardware serial numbers, network addresses, or other sensitive diagnostic data.

If that private reporting channel is unavailable, retain the report privately and contact a maintainer through an already verified private channel. This repository does not publish or imply a security-reporting email address.
