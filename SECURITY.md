# Security Policy

Once GitHub private vulnerability reporting is enabled for this project, report suspected vulnerabilities through that private channel.

Do not open a public issue containing exploit details, credentials, tokens, recovery material, host identifiers, hardware serial numbers, network addresses, or other sensitive diagnostic data.

Until a private reporting channel is published, retain the report privately and contact a maintainer through an already verified private channel. This repository does not publish or imply a security-reporting email address.
